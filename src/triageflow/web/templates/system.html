How a priority is decided
  1. Code validates the intake and calculates the SATS/TEWS priority — no model involved.
  2. The model reads the free-text complaint and suggests signs; the nurse accepts or rejects each.
  3. The priority is the most urgent of the TEWS band and the nurse-confirmed signs.
  4. Every point is cited and re-checked against the protocol text before approval.
  5. A named clinician confirms — only then does the patient join the queue.
